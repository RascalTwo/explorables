Pairwise Sorter

You are the comparator — ~n·log₂n choices instead of ranking the whole list in your head.

Driving this with an AI? Don't click through the UI — this page exposes a scripting API at window.pairwiseSorter. Run window.pairwiseSorter.help() in the page console for the full surface (load items, read state, export, answer, everything the buttons do).

Paste a full export — items and comparisons. It lands as a new list, so nothing you already have is touched.

One item per line — plain text, markdown links, pipe-separated fields, or a JSON array.

    Pipe fields are matched by content, not order. A URL ending in a media extension (jpg png gif webp avif svg mp4 webm mov) is always media; the first URL without one becomes the link; every other URL is media too. First plain text is the title, the rest is the description. Videos render with controls; gifs just work as images.

    JSON field aliases: media/images/img/image/thumbnail (string or array), url/link/href, title/name/label, desc/description/subtitle, tags/tag/labels/categories.
