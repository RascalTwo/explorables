F5 in an AI Solution Architecture

How F5's product portfolio positions itself across the lifecycle of an AI request — data ingest → inference → APIs → agents → public edge → multicloud.

Snapshot: 2026‑06‑30 · derived from F5's AI Reference Architecture and 2026 product‑status research. Click any box for detail.

F5's pitch: an AI app is just a new (and uglier) kind of application traffic — LLM calls, RAG pipelines, agent‑to‑agent chatter, GPU clusters — so the things F5 has always done (load balancing, WAF, API security, traffic steering) now need doing for AI workloads. Everything below is a module or feature of one umbrella, the F5 Application Delivery & Security Platform (ADSP), organized into four pillars: Deliver AI, Secure AI, Scale AI, Connect AI. The one product the research flags: F5 AI Gateway — the Nov‑2024 standalone LLM proxy — has been functionally succeeded by F5 AI Guardrails (the CalypsoAI runtime). It's still a SKU; it's not where F5 points new customers. On 22 Jun 2026 F5 consolidated its AI‑security story into the F5 AI Security Platform — five pillars (Governance, Discovery, Security Testing, Runtime Protection, Observability) anchored by a second acquisition, SurePath AI (network‑based AI discovery / shadow‑AI detection) — and again did not name AI Gateway.

On F5 AI Gateway: launched Nov 2024 as a K8s/Helm proxy (Core + Processors, ~v1.3). The research grades it harvest mode — docs URL 301‑redirects to a marketing page (the changelog sub‑page redirects too as of mid‑2026), the DevCentral intro article is archived, it's absent from two consecutive earnings calls (Q1 + Q2 FY26) and from AppWorld 2026, and F5's own /ai, /products/ai-guardrails, and campaign pages don't name it. The CalypsoAI acquisition ($180M, closed Sept 2025) → F5 AI Guardrails + F5 AI Red Team now occupies the same architectural slot with a more polished install path (certified OpenShift Operator). On 22 Jun 2026 F5 launched the F5 AI Security Platform (Governance / Discovery / Security Testing / Runtime Protection / Observability) and a second acquisition, SurePath AI (AI Discovery / shadow‑AI detection) — and once more did not name AI Gateway, hardening the harvest read.  ·  Phoenix / OpenTelemetry note: F5's telemetry uses a proprietary attribute schema, not OpenInference — an OTel‑Collector remap shim is needed to integrate Arize Phoenix.
