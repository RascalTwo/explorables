You have a skill. Here’s how to use it in any AI.

A skill is a folder with a SKILL.md file in it: instructions, plus optional scripts and reference files, that teach an AI how to do one job. Since early 2026 nearly every major AI reads the same format — but each one wants the folder in a different place, and a few are strict about what’s inside. This page covers both sides.
