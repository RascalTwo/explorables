Snapshot 2026‑05‑12 · sourced from the deep-research report · both vendor tools are beta/days-old — specifics will drift

OpenAI Codex Chrome extension

Web Store extension ↔ native-messaging host ↔ Codex app. Drives your real signed-in Chrome. Launched May 7 2026.
  • Zero-config: Codex app → Plugins → add Chrome plugin
  • Bundled with ChatGPT Plus/Pro/Business/Enterprise (temp. Free/Go)
  • Tab-groups-per-thread; can access browser history (per-request)
  • Locked to ChatGPT / Codex
  • Chrome only — no Edge / Firefox / Brave
  • Broad Chrome permissions (debugger, history, modify site data)
  • Best if you already live in ChatGPT

Anthropic Claude Code + Chrome

Web Store extension ↔ native-messaging host ↔ Claude Code CLI / VS Code. Drives your real Chrome or Edge. Beta.
  • Strongest default guardrails (category blocklist, per-domain JS approval, no autonomous mode)
  • claude --chrome / /chrome; auto in VS Code
  • GIF session recording built in
  • Requires a direct Anthropic plan — not via Bedrock / Vertex / Foundry
  • Chrome + Edge only; no Brave/Arc; no WSL
  • 2 disclosed extension CVEs in 2026 (ShadowPrompt, ClaudeBleed) — both patched
  • Best if you already live in Claude Code / VS Code

Microsoft · OSS Playwright MCP

MCP server (stdio / HTTP). Launches its own Playwright browser — isolated by default. Apache‑2.0, free.
  • No lock-in — any model, any MCP client; self-hostable, Docker
  • Chromium + Firefox + WebKit + Chrome channels
  • Testing-grade: network mocking, tracing, video, assertions
  • Accessibility-tree first — "no vision models"
  • "Not a security boundary" — guardrails are the client's job
  • ~13.7K tokens/request just for tool definitions
  • Best for portability, self-hosting, web testing, custom agents

All three share the same core promise — build your app, then test/debug/operate it in a browser without leaving the agent — and the same core risk: prompt injection from page content. The real fork is vendor bridge vs. agnostic server. "Uses your real browser" is convenience and attack surface; Playwright MCP's isolated-by-default browser has the smaller blast radius. Token cost is now a first-class criterion — leaner agnostic peers (browser-use ~89% WebVoyager @ 200–400 tok/page, Vercel agent-browser, Playwright CLI+skills) undercut Playwright MCP's overhead.
