Rough.js playground

A hand-drawn test bench for Rough.js 4.6.6. Everything on this page is drawn by the library — no CSS tricks, no filters. Slider & select controls change real Rough.js options and redraw instantly; the Boil buttons up top nudge every live sketch's random seed (that's the "jittery Excalidraw" effect). Same seed ⇒ same wobble, always.

5 · A diagram, Excalidraw-style — boxes, arrows, arrowheads, notes

      
Rough.js draws shapes only — no arrowheads, no text. Arrowheads here are two extra linearPath strokes; labels are ordinary SVG text in a handwriting font. Click any box for what it does.

7 · Plus Ultra — what can a wobbly pen say?

      
Not options this time — ideas (including a real architecture diagram of the conversation that built this page, and two working tools: a trust dashboard and a diagram editor). Each scene uses the hand-drawn look to carry a meaning that a crisp chart can't: uncertainty, draft-ness, emphasis, light, sequence, choice. Every one is interactive; pick a scene, then poke it. The boil controls up top re-seed whichever scene is showing.
