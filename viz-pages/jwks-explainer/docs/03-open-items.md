## Open — needs a human call

### O1 · Posture is still `local` — **neither page is published**

Applies to **all four**: `jwks-explainer/`, `jwks-diagrams/`, `token-compromise-map/` and `token-kill-switch/`. Each `index.html` carries `viz:posture=local` / `viz:listed=unlisted`, the safe
bootstrap default. Both were *designed* to be shareable — generic, and sweeping
clean of internal names — but publishing is outward-facing and was not
authorised, so they were left closed.

To open them up, edit the metas via `manage.ts` rather than by hand:

```bash
bun "$SKILL_DIR/manage.ts" update viz-pages/jwks-explainer --posture public --listed listed
bun "$SKILL_DIR/manage.ts" update viz-pages/jwks-diagrams  --posture public --listed listed
bun "$SKILL_DIR/manage.ts" update viz-pages/token-compromise-map --posture public --listed listed
bun "$SKILL_DIR/manage.ts" update viz-pages/token-kill-switch    --posture public --listed listed
```

**Publish them as a set** — all four cross-link, so a partial publish leaves live pages pointing at 404s. **If only one gets published, publish all** — they cross-link, and a live page
linking to a 404 is worse than neither being up.

Then build and deploy as a separate, confirmed step. If they go public each should
get an OG card — scaffold, rather than copying a sibling's:

```bash
bun "$SKILL_DIR/bootstrap.ts" jwks-explainer --hero   # then verify.ts --og
bun "$SKILL_DIR/bootstrap.ts" jwks-diagrams  --hero
```

For `jwks-diagrams` the level-4 figure (X.509 versus JWK) is the one to put on
the card — it carries the argument with no reading required.

## Verification — how to re-check this page

### External links — added 2026-08-07

Every `.elsewhere` block points at somebody else's page, and somebody else's page
is what 404s in six months. A page full of dead further-reading links is worse
than never having offered any — it is precisely the impression they exist to
prevent.

```bash
bun viz-pages/check-links.ts          # exits non-zero on any dead link
```

It scans `.js`/`.ts` as well as `.html`. An earlier version reported
*"2/2 reachable"* while silently missing a link generated by a `content.js`
helper — **a checker that quietly skips things is indistinguishable from a
passing one.** Currently 10/10 in this repo.
