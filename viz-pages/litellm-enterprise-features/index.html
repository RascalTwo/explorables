⚠️ "Honor-system" — a third category
Three layers are independent: the license (the repo LICENSE makes everything outside enterprise/ MIT), the code gate (a runtime premium_user check), and the docs marketing. A few features the docs label "✨ Enterprise" have no code gate and live in the MIT tree — so they run on OSS and using them is not a license violation. But the vendor sells them: they may add a gate in a future release (breaks on upgrade), ship no support/SLA, and you're leaning on the paid tier against intent.
