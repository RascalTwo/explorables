PingOne Multi-Identifier Login Lookup — many usernames, one account

Claim 2 of the DaVinci verification. A user has one primary username plus an array of alternate identifiers on a multi-valued custom attribute. Whichever one they type into the login box, a single SCIM eq query resolves it to the same account — no loop required, because eq on a multi-valued attribute matches any element server-side.
Requires usernames to be unique across the entire system — which they currently are.
