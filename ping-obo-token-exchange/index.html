Calls to PingOne

The only network calls the gateway makes to PingOne. Everything else — signature, issuer, audience, scope, act — is verified locally.

POST /as/token · grant=client_credentials
gateway's id+secret → actor_token
POST /as/token · grant=token-exchange
subject + actor → delegated token
No /as/introspect. Tokens are JWTs — signature is checked against the cached JWKS, and iss / aud / scope / act are all checked in-process. The single per-token dependency on PingOne is the JWKS, and that's cached.
In short: the gateway fetches its own actor_token, then calls grant_type=…:token-exchange. The downstream API validates each token against the cached JWKS (signature + issuer) and checks scope + the act claim.
